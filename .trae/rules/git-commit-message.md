Use conventional commits format. All messages must be in English.

**Format:**
```
<type>(<scope>): <short description>

<optional body>
```

**Allowed types:** feat, fix, docs, style, refactor, perf, test, chore, build, ci

**Rules:**
- Subject line ≤ 72 characters, imperative mood (e.g. "add" not "added")
- Body wraps at 72 characters, optional
- Reference issue numbers as `#123` when applicable
- No trailing punctuation in subject
